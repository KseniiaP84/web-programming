
# Веб-програмування — Лабораторна робота №1

![CI Status](https://github.com/KseniiaP84/web-programming/actions/workflows/ci.yml/badge.svg?branch=feature-cicd-pipeline)

Проєкт для вивчення системи контролю версій Git та налаштування автоматизованого CI/CD пайплайну на PHP.

## Опис проєкту

Лабораторна робота присвячена налаштуванню GitHub Actions, автоматизованому тестуванню за допомогою PHPUnit та статичному аналізу PHP-коду.

## Використані технології

- Git та GitHub
- GitHub Actions
- PHP 8.2
- PHPUnit
- Статичний аналіз коду

## CI-пайплайн

Пайплайн автоматично запускає перевірки коду після відповідних змін у репозиторії. Результат виконання перевірок відображається у бейджі статусу CI.
